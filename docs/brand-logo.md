# Voya Story Globe

The globe replaces the compass in the shared BrandMark component and sign-in
card. The original supplied concept includes a wordmark; the website uses only
the illustration beside its existing accessible Voya name.

Assets: `public/brand/voya-globe.webp` (256px transparent WebP) and
`public/brand/voya-globe-icon.png` (64px browser icon).
The header/footer mark displays at 48px on mobile and 52px on desktop.
Account branding uses 40–48px; the sign-in card uses 36px inside its existing badge.
Dark backgrounds use a warm light CSS treatment of the same transparent shape.

The built-in image editing tool prepared the transparent source from the supplied
concept; Sharp resized and encoded the web assets. Editing prompt:

> Use case: background-extraction. Edit target: supplied Voya Story Globe logo screenshot. Extract ONLY the globe illustration at the left, including mountain, palm tree, pagoda, birds and paper airplane and its curved trail. Remove all text, labels, Voya wordmark, WORLD INSIGHTS, border, paper background. Preserve the globe's design, shapes and warm dark brown/olive ink colors faithfully. Clean crisp logo edges, no redesign, no new details, no shadow. Actual transparent background including ocean/negative space within globe. Center the isolated mark on a square canvas with small 5% clear margin, filling 90% of canvas, suitable for a website navbar icon. Output a transparent PNG and provide the local output file path for integration into the website.
